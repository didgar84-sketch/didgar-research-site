سلسلة الحساب

تصل المدخلات إلى الفحص والتحليل ثم الأرقام والجداول والأشكال والنص. يحدّث الحساب داخل السطر قيم الجمل مع الجداول عند تغير البيانات. يقلل ذلك التناقض اليدوي ولا يثبت صحة المنهج.

تظل الأطروحة محتاجة لسؤال وحجة وطريقة وتفسير بشري. ابدأ بقالب الجامعة؛ إنتاج PDF لا يعني اعتماد تنسيقه.

مشروع المثال

تتضمن الحزمة بيانات اصطناعية كاملة وكود Python وREADME ومخرجات متوقعة وQMD. المسارات نسبية ولا مفاتيح سرية. افصل المدخلات عن النتائج وأرفق القاموس.

شغّل python research.py أولاً لإنتاج ملخص وجدول ستة مسارات وSVG بلا حزم إحصائية خارجية. يحتاج Quarto ومحرك Jupyter إعداداً إضافياً موضحاً في README.

الأرقام في النص

تحسب خلية Python المتغير mean_score وتدرجه عبارة {python} mean_score في الجملة. لا تعِد كتابة الرقم يدوياً وطابق معرفات الجداول والأشكال بالمستند.

غيّر درجة في نسخة تعليمية وأعد التنفيذ، ثم تحقق من تطابق المتوسط والجدول والرسم والجملة مع الإصدار نفسه. احفظ بصمة البيانات أو معرف إصدارها.

التنفيذ النظيف

شغّل ببيئة جديدة وترتيب موثق. سجل نسخ Python وQuarto والحزم؛ البذرة وحدها غير كافية. قد تكون النتائج المخزنة مؤقتاً قديمة، فحدد أمر البناء.

افحص الأعداد والمدى والوحدات والتحويل والعينة وحالات الإجابة المعروفة. المثال وصفي وليس منهجاً مثبتاً لكل أطروحة.

الاتجاه والصيغ

افصل اتجاه HTML عن الكود وDOI اللذين يقرآن من اليسار. يحتاج Word أنماطاً واتجاه فقرات مناسبين، ويحتاج PDF محركاً وخطاً يدعمان اللغة مع اختبار حقيقي.

راجع الفهرس والترقيم والحواشي والمراجع الثنائية والجداول وفواصل الصفحات في كل صيغة. وثق التعديل اليدوي اللاحق وكيفية إعادة إنتاج النسخة.

ابدأ بالتحليل الأساسي

تختلف متطلبات تقدير نسبة ومقارنة متوسطات والانحدار والعينة العنقودية وتحليل البقاء. لا تناسب معادلة مسح بسيط تلقائياً نموذجاً معقداً أو دراسة نوعية. حدّد النتيجة والتصميم أولاً.

افتراضات يمكن الدفاع عنها

يتطلب حساب القوة اختباراً مناسباً وحجم أثر ومستوى خطأ وقوة واتجاه الاختبار ونسبة تخصيص. برّر الأثر بدليل سابق أو حد مهم علمياً أو سيناريو منطقي. اختياره فقط لتقليل التكلفة ليس تبريراً علمياً.

الدقة والتصميم الفعلي

قد يكون الهدف فترة تقدير دقيقة بدلاً من تجاوز عتبة الدلالة. القياسات المتكررة والتجمع وعدم التوازن قد تستلزم طريقة متخصصة أو محاكاة. أمثلة G*Power لدى UCLA خاصة باختبارات محددة؛ افحص ملاءمتها للتصميم.

الانسحاب والحساسية

عند الحاجة إلى n ملاحظات قابلة للتحليل مع انسحاب متوقع r، يكون n/(1−r) تقريباً بسيطاً للاستقطاب تحت افتراضات معلنة، مع التقريب للأعلى. قارن سيناريوهات معقولة للأثر والانسحاب. لا تستبدل فترات التقدير أو التبرير الأولي بقوة محسوبة بعد النتائج.

التوثيق القابل لإعادة الحساب

احفظ الأداة والنسخة والاختبار وكل المدخلات ومصادر الافتراضات ونتائج السيناريوهات. فسّر كفاية العدد بالنسبة لنتيجة وافتراضات محددة، لا بوصفه رقماً عاماً. يتطلب القرار النهائي مراجعة التصميم والموارد الفعلية.

قائمة تنفيذ البحث

  • تطابق الاختبار والتصميم.
  • تبرير الأثر والدقة.
  • مراعاة التجمع والانسحاب.
  • حفظ المدخلات وسيناريوهات الحساسية.

هذه حالة تعليمية افتراضية؛ لا تستخدم الأعداد والنص كنتائج دراسة فعلية.

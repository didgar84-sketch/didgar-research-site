رواية تحليلية مع الشفرة

اشرح الهدف ومصدر البيانات والتحويلات والافتراضات والتفسير بجانب الكود. يجمع Jupyter النص والشفرة والمخرجات؛ ينبغي أن يحافظ تقرير R على الاستدلال القابل للتتبع نفسه.

التخلص من حالة الجلسة الخفية

قد يعيد تشغيل الخلايا خارج الترتيب استخدام متغيرات قديمة. أعد تشغيل البيئة ونفّذ كل الخطوات بالترتيب. قد تنتمي المخرجات المحفوظة لنسخة سابقة؛ جهّز تنفيذاً نظيفاً قبل النشر.

المدخلات وبيئة التنفيذ

وثّق نسخ اللغة والحزم وإنشاء البيئة والبذرة والمسارات. البذرة الثابتة وحدها لا تضمن التطابق على جميع الأجهزة. وفّر بيانات مسموحة أو بيانات تعليمية موضّحة وفسّر قيود الوصول. أبقِ المفاتيح والبيانات السرية خارج المستودع.

التنظيم والفحص

انقل المنطق المتكرر إلى دوال وأضف فحوصاً ذات معنى للمدى وعدد السجلات والإجابات المعروفة. استخدم مسارات نسبية موثقة وافصل الخام والمعالج والمخرجات واحفظ قرارات التحويل.

حزمة قابلة لإعادة التشغيل

ضمّن README وأمر التنفيذ والبيئة والمدخلات والمخرجات المتوقعة والدفتر المنفذ. يجب ألا يحتاج الزميل خطوات خفية. يساعد HTML وPDF القراءة لكنهما لا يستبدلان الشفرة والبيئة اللازمة للإعادة.

قائمة تنفيذ البحث

  • تنفيذ نظيف بالترتيب.
  • توثيق النسخ والإعداد.
  • شرح المدخلات والمخرجات والمصدر.
  • إرفاق التوثيق والفحوص العلمية.

حالة تعليمية وقرارات التنفيذ

هذه حالة تعليمية افتراضية؛ لا تستخدم الأعداد والنص كنتائج دراسة فعلية.

قد يعرض الدفتر مخرجاً جميلاً يعتمد على متغير من جلسة سابقة. أعد النواة وشغل الخلايا بالترتيب؛ يكشف الاسم غير المعرف مشكلة حالة. المخرج القديم ليس إعادة إنتاج. سجل البيانات والبيئة والبذور والأوامر وطابق النص والأشكال؛ لا يضمن جهاز واحد جميع الأنظمة.

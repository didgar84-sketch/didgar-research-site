مناسبة لتحليل البيانات، التعلم الآلي وتطوير الويب الخفيف. الحزم الأساسية: NumPy, Pandas, scikit-learn, TensorFlow، وتوصيات حول تنظيم المشروع وvirtualenv/conda.

R

C++, Java, JavaScript, SQL

شفرة علمية قابلة لإعادة الإنتاج

لا يكفي تشغيل شفرة على جهاز واحد. وثّق المدخلات والمخرجات والبيئة والاعتماديات والافتراضات. لا تضع بيانات الدخول في الشفرة، وتجنب تسرب البيانات في المعالجة واختيار النموذج.

  • README بتعليمات تشغيل دقيقة ومدخلات نموذجية
  • توثيق إصدارات الاعتماديات والتراخيص
  • اختبارات مفيدة ومثال أدنى قابل للتكرار
  • توثيق التحقق والقيود والتكلفة الحاسوبية

بنية مقترحة للمشروع العلمي

project/
  README.md
  requirements.txt
  src/
  tests/
  data/README.md
  outputs/

اشرح مصدر البيانات وتراخيصها وإعدادها. لا يلزم وضع الملفات الحساسة في المخزن. افصل المخرجات القابلة للتوليد عن الشفرة، واحفظ مفاتيح الدخول خارج التحكم بالإصدارات.

التحقق من المحاكاة

ابدأ بحالة بسيطة ذات سلوك معروف أو متوقع نظرياً قبل السيناريوهات المعقدة. وثّق الحساسية للمعلمات والخطوة والبذور العشوائية. الدقة العددية ليست صلاحية النموذج؛ الحساب الدقيق لافتراض غير مناسب قد يضلل. اشرح حدود الاستخدام وتغيير المعلمات.

حالة تعليمية وقرارات التنفيذ

هذه حالة تعليمية افتراضية؛ لا تستخدم الأعداد والنص كنتائج دراسة فعلية.

يحتوي المشروع التعليمي على ١٢ سجلاً اصطناعياً وكود Python بالمكتبة القياسية. يفحص المدخل ويلخص البيانات ويولد ستة مسارات انحدار وبصمة الملف. يوضح خط التنفيذ ولا يقدم أدلة فعلية. اعتماديات Quarto منفصلة؛ لا يثبت إنشاء ملف صلاحية النموذج، وتتحقق اختبارات الجواب المعلوم من الحساب ضمن حدودها.

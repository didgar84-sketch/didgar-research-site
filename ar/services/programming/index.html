البرمجة العلمية والمحاكاة البحثية

تنفيذ الخوارزميات والمحاكاة باستخدام Python وR وMATLAB؛ مع الشفرة وبيئة تشغيل موثقة والتحقق من النموذج وإعادة إنتاج النتائج.

الخدمات البحثية

  • Python (NumPy, Pandas, Scikit-learn, TensorFlow)
  • MATLAB/Simulink لمحاكاة الأنظمة
  • R و RStudio للتحليلات الإحصائية المتقدمة
  • C++, Java, JavaScript للمشاريع البرمجية
  • محاكاة الأنظمة المعقدة والنمذجة الرياضية
  • خوارزميات الذكاء الاصطناعي والتعلم الآلي
  • تطوير تطبيقات الويب والهاتف المحمول
  • معالجة الصور والرؤية الحاسوبية

المخرجات المتوقعة

  • نطاق وخطة متفق عليهما
  • ملفات قابلة للتحرير أو شفرة ملائمة
  • توثيق الطرق والافتراضات والقرارات
  • ملاحظات المراجعة ودليل الاستخدام

ما المطلوب قبل البدء

  • السؤال والتخصص ومرحلة البحث
  • تعليمات المؤسسة أو المجلة والموعد
  • النص الحالي أو بيانات مسموحة منزوعة الهوية
  • المخرجات المطلوبة وتعليقات المشرف
يُحدد النطاق والتكلفة والأدوات والوقت والمراجعات والدعم كتابةً، ويبقى الباحث مسؤولاً عن فهم العمل واعتماده.

مراحل التعاون

  1. مراجعة الموضوع والمرحلة والبيانات والموعد.
  2. الاتفاق على المخرجات والجدول والتكلفة.
  3. تسليم مخرجات المراحل وتقارير التقدم.
  4. مراجعة المنهج والتحليل والمصادر وجودة النص.
  5. تسليم الملفات القابلة للتحرير والشفرات والتوثيق المتفق عليه.

أدلة ذات صلة

  • البرمجة البحثية والمحاكاة القابلة لإعادة الإنتاج
  • إدارة بيانات البحث وإعادة إنتاج النتائج
  • مقارنة البرامج الإحصائية؛ SPSS وR وPython
  • دفاتر حسابية قابلة لإعادة التنفيذ؛ Jupyter وR والبيئة
  • أطروحة حسابية بـ Quarto؛ البيانات والجداول والأشكال والنص
  • مقالات البرمجيات البحثية والاستعداد لـ JOSS

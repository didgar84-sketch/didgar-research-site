# گزارش بررسی و اصلاح نسخۀ ۲.۱.۰

## نتیجۀ اجرایی

تغییرات خواسته‌شده در همۀ ۱۲۶ صفحۀ فارسی، عربی و انگلیسی و در نسخۀ HTML مستقل اعمال شدند. تمام آزمون‌های خودکار فهرست‌شده در این گزارش موفق بوده‌اند. بررسی کامل روابط URL، ساختار HTML، دارایی‌ها، JSON-LD و رفتارهای برنامه انجام شده است. تأیید نهایی ظاهر روی مرورگر و دستگاه واقعی، کارایی کاربران و سئوی استقرار زنده در این محیط انجام نشد؛ این موارد از نتایج تأییدشده جدا هستند.

## تطبیق با درخواست

| درخواست | نتیجۀ اجرا |
|---|---|

| Instagram و ایتا | افزوده شدند؛ ایتا دارای نشان رسمی است |

| حذف جمله‌های زیر تصاویر | همۀ figcaptionهای قالب از همۀ صفحات و HTML مستقل حذف شدند |
| بزرگ‌ترشدن نام مؤسسه کنار لوگو | اندازۀ متن و نشان افزایش یافت؛ در موبایل ردیف کامل برند |

هدف طراحی، هویت رسمی و خوانا با ترکیب سرمه‌ای و طلایی، نام برند برجسته، کارت‌های منظم، راه‌های تماس واضح و استفاده آسان از مجموعه پژوهشی است. مجموعه فعلی ۲۸ موضوع در سه زبان و ۳۴ منبع دارد؛ تبدیل‌شدن به مرجع جهانی با توسعه و بازبینی تخصصی پیوسته محتوا سنجیده می‌شود.

## سئوی فنی

- ۱۲۶ عنوان و ۱۲۶ توضیح صفحه یکتا و متناسب با مسیر بررسی شدند؛ H1 اصلی در هر صفحه دقیقاً یک مورد است.
- صفحه اصلی فارسی canonical ریشه دارد. `/fa/` در sitemap نیست و به ریشه انتقال دائمی دارد. نسخۀ انگلیسی و عربی canonical مستقل دارند.
- hreflang فارسی، انگلیسی، عربی و x-default با URL همان موضوع، روابط برگشت و sitemap تطبیق داده شدند.
- نقشۀ سایت همۀ صفحات اصلی را یک بار معرفی می‌کند؛ تصاویر موضوعی و تاریخ‌های معتبر دارد.
- JSON-LDهای Organization، WebSite، WebPage/CollectionPage، BreadcrumbList، Article، Service و ItemList به موجودیت‌های مرتبط متصل‌اند. ۸۴ Article و ۱۸ Service بررسی شدند.
- مشخصات نویسنده سازمانی مقاله‌ها با نام، نوع و نشانی روشن تکمیل شد. تاریخ ویرایش مقاله با تاریخ قابل مشاهده و sitemap منطبق است؛ تاریخ انتشار حدس زده نشده است.
- تصویر معرفی‌شده در Article همان تصویر قابل مشاهده صفحه است. معرفی خدمات و منابع به معنی تأیید یا وابستگی سازمان‌های نام‌برده نیست.
- Open Graph و Twitter با عنوان، توضیح، URL و تصویر JPEG با ابعاد ۱۲۰۰×۶۳۰ تطبیق داده شدند.
- متن کامل راهنماها در HTML موجود است؛ خواندن صفحات اصلی سایت به رندر JavaScript وابسته نیست.
- بررسی گراف لینک‌ها، دسترسی از خانه به تمام ۱۲۶ صفحه را تأیید کرد؛ صفحه یتیم در این گراف وجود ندارد.
- ۳۲۴ انتقال دائمی، حفظ query، نرمال‌سازی اسلش و پاسخ 404/noindex آزموده شدند.
- canonical و sitemap با دامنه production یا SITE_URL ساخته می‌شوند. Preview دارای noindex است و crawler می‌تواند آن را بخواند.
- فایل HTML مستقل noindex است. مسیرهای fragment آن برای مشاهده آفلاین‌اند؛ URLهای مستقل انتشار در بسته چندصفحه‌ای هستند.

این تنظیم‌ها با راهنماهای رسمی Google Search Central درباره عنوان‌ها، canonical، نسخه‌های زبان، sitemap و داده ساختاریافته کنترل شده‌اند. نتیجه آن صحت روابط بررسی‌شده است؛ نمره یا رتبه جست‌وجو از این آزمون‌ها استخراج نمی‌شود.

## تصاویر، فونت و حجم

۳۸۷ عنصر تصویر، ۲۶۱ جایگاه picture و ۱۵۶۶ گزینۀ تصویر پاسخ‌گو در HTMLهای اصلی بررسی شدند. ابعاد ذاتی فایل، alt، وجود فایل و انتخاب eager/high برای تصاویر اصلی کنترل شد. تصاویر خارج از بخش اصلی lazy هستند. AVIF و WebP در اندازه‌های ۴۸۰، ۸۰۰ و ۱۲۰۰ پیکسل موجودند.

فونت‌های واقعی با رمزگشایی WOFF2 بررسی شدند: Vazirmatn با ۸۱۱ نویسۀ نگاشت‌شده و وزن ۱۰۰ تا ۹۰۰؛ Cairo با ۶۹۹ نویسۀ نگاشت‌شده و وزن ۲۰۰ تا ۱۰۰۰. نویسه‌های نمونۀ فارسی و عربی در فایل‌های درست موجودند. فایل‌ها محلی‌اند، font-display:swap دارند و فونت زبان اصلی preload می‌شود. انتخاب lang برای عبارت‌های عربی در صفحۀ فارسی نیز اعمال می‌شود. مجوزهای OFL در بسته و HTML مستقل نگه‌داری شده‌اند.

CSS اصلی حدود ۲۲ کیلوبایت و JavaScript اصلی حدود ۷ کیلوبایت است. این اعداد اندازۀ فایل‌اند؛ زمان بارگذاری و Core Web Vitals با آن‌ها اندازه‌گیری نمی‌شود. برای LCP، INP و CLS باید داده آزمایشگاهی و سپس داده کاربر واقعی در استقرار نهایی ثبت شود.

## دسترس‌پذیری و تعامل

نام برند مجاور لوگو، برچسب قابل دسترس آن است و لوگوی تکراری به‌صورت تزئینی مشخص شده است. دکمه‌های تماس نام قابل دسترس و SVG تزئینی دارند. نشان تلفن، شمارۀ واضح با جهت LTR و پیوند tel ارائه می‌کند. نوار زبان‌ها یک nav با نام مشخص است و هر گزینه lang/dir درست دارد.

منوی کوچک با Escape بسته می‌شود، فوکوس را به دکمه برمی‌گرداند و با انتخاب لینک جمع می‌شود. ارزیابی کنتراست ۱۰ زوج رنگ تعریف‌شده موفق بود: متن اصلی ۱۳٫۶، متن ثانویه ۵٫۷۳، طلایی روی پس‌زمینۀ روشن ۶٫۷ و مرز فیلدها ۳٫۷۴. حالت hover دکمه‌های شفاف و لینک‌های روی فرم سفید اصلاح شد. نیازهای حرکت کمتر در تغییرات جدید رعایت شده‌اند. این محاسبات، بررسی ترکیب تمام لایه‌ها در مرورگر یا ادعای انطباق کامل WCAG نیست.

فرم در آنلاین و آفلاین، طول متن، فضای خالی، تاریخ غیرممکن، رضایت، نوع داده و فیلد ضد هرزنامه را کنترل می‌کند. نوع محتوای API به JSON محدود شده است. پیام آفلاین، عنوان و برچسب‌های همان زبان را دارد. پاسخ آماده‌شدن پیوند با ارسال واقعی پیام اشتباه گرفته نمی‌شود.

بدون JavaScript، منو در تمام اندازه‌های پوشش‌داده‌شده توسط CSS باز و قابل دسترسی است. فیلترها و ابزارهای وابسته به JavaScript پنهان می‌شوند و راهنمای استفاده نمایش داده می‌شود. کنترل‌های فرم مشاوره پنهان و لینک مستقیم واتساپ ارائه می‌شود. روش POST از ارسال اطلاعات شخصی در query نشانی جلوگیری می‌کند.

## منابع پژوهشی

تمام ۳۸ URL فهرست منابع برای دسترسی بررسی شدند. ۳۵ مورد مستقیماً محتوای معتبر دریافت کردند. DataCite و Think. Check. Submit. در آزمون مستقیم پاسخ 403 داشتند ولی وجود و محتوای صفحات رسمی با بازیابی وب تأیید شد. دسترسی به صفحۀ APA در محیط بررسی تأیید نشد؛ این وضعیت اثبات خراب‌بودن پیوند نیست. مقصدهای تلگرام و اینستاگرام همان لینک‌های ارائه‌شده توسط شما هستند؛ تأیید زنده حساب‌ها با ابزار بازیابی ممکن نشد.

PRISMA 2020، نسخه‌های ۲۰۲۵ CONSORT/SPIRIT، پیش‌ثبت COS و الزامات نویسندگی ICMJE به‌صورت مستقیم از صفحات رسمی مرور شدند. منابع دانشگاهی، ابزارهای آمار، DOI و مدیریت داده در فهرست قابل مشاهده‌اند. بررسی دسترسی URL با تأیید علمی تمام ادعاهای منابع برابر نیست. یک ناهماهنگی کوچک در تعداد ستون‌های جدول پیشنهادی راهنمای فارسی گزارش‌دهی نیز اصلاح شد.

## نتایج واقعی آزمون‌ها

| آزمون | نتیجه |
|---|---|
| `check.mjs` | ۱۲۶ صفحه؛ لینک و ID، زبان، JSON-LD و API؛ موارد مرزی تاریخ/رضایت/JSON موفق |
| `seo-check.py` منبع و dist | ۵۳۶۱ رابطۀ لینک/دارایی؛ ۳۸۷ تصویر؛ ۸۴ Article؛ ۱۸ Service؛ ۱۵۶۶ گزینۀ srcset؛ تمام صفحات قابل دسترس |
| `interaction-check.mjs` | جست‌وجوی چندواژه با یکسان‌سازی فارسی/عربی، دسته‌بندی، DOI و ورودی ناامن، برنامه‌ریز و فرم آنلاین/آفلاین موفق |
| `standalone-check.py` | ۱۲۶ template، ۳۸۷ تصویر، ۲۶۱ picture، ۱۹ تصویر صفحۀ اصلی، دو فونت، مسیر و نحو JS موفق |
| `release-check.py` | حذف بخش‌ها در تمام صفحات، ۱۵ دکمۀ تماس در سه زبان، نمادها، فونت‌ها و ساختار نسخۀ مستقل موفق |
| `build-check.mjs` | مبدأ production، دامنه سفارشی، Preview/noindex، توکن تأیید و رد ورودی نامعتبر موفق |
| `http-check.mjs` | ۱۲۶ صفحه HTTP، ۳۲۴ انتقال، HEAD، 404، دارایی‌ها و API موفق |
| تجزیۀ CSS | ۳۹۶ قاعدۀ CSS اصلی بدون خطای نحوی، با css-tree |
| فایل فونت | خانواده، وزن، نویسه‌های نمونه و سلامت رمزگشایی موفق |
| زوج رنگ‌های اصلی | ۱۰ بررسی عددی نسبت کنتراست موفق |

آزمون تعامل JavaScript با سازگارکنندۀ DOM انجام شده است؛ این آزمون رندر مرورگر نیست. نمونه‌های فرم آزمایشی و ساختۀ آزمون بوده‌اند و آزمون‌ها فقط آماده‌شدن پیوند را کنترل می‌کنند.

## حدود بررسی و کنترل پس از انتشار

مرورگر محلی نصب‌شده‌ای در دسترس نبود و دریافت فایل اجرایی نیز به آرشیو معتبر نرسید. مرورگر ابری نشانی localhost را مسدود کرد؛ بازکردن file نیز به دلیل سیاست امنیتی مجاز نبود. ادامه این مسیر متوقف شد. بنابراین آزمون بصری دسکتاپ/موبایل، آزمون واقعی صفحه‌کلید در مرورگر، Lighthouse و Core Web Vitals جزو نتایج تأییدشده نیستند.

انتشار در Vercel، وضعیت واقعی Google Search Console، مالکیت دامنه و نمایه‌شدن در این درخواست انجام نشد. پس از انتشار، مبدأ اصلی، صفحات نمونه هر زبان، انتقال‌ها، 404، Rich Results Test، PageSpeed Insights و ثبت sitemap باید روی دامنه واقعی کنترل شوند. پرونده `scripts/browser-check.mjs` برای بررسی روی دستگاه دارای Playwright/Chromium همراه بسته است.

جزئیات قابل بازبینی: `reference/qa/validation-current.txt`، `validation-current.json`، `release-check.json`، `font-validation.json`، `contrast-validation.json`، `css-validation.json` و `external-link-audit.json`. مدارک قدیمی در `reference/previous` سابقۀ ورودی هستند؛ مرجع نتایج این ویرایش، گزارش جاری است.

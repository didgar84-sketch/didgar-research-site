# وب‌سایت سه‌زبانه مؤسسۀ پژوهشی دکتر دیدگر — نسخهٔ اصلاح‌شدهٔ سئو

این بسته ۶۹ نشانی اصلی دارد: ۲۳ صفحه در هر زبان فارسی، انگلیسی و عربی. محتوا در HTML آماده است و برای خواندن صفحات منتشرشده به JavaScript وابسته نیست. نسخهٔ حاضر روی فایل ZIP ضمیمه اصلاح شده است. گزارش این بررسی در **SEO-AUDIT-FA.md** و منابع در **SOURCES.md** قرار دارند.

## انتشار روی Vercel

۱. محتویات پوشهٔ `didgar-site` را در ریشهٔ مخزن پروژه قرار دهید؛ `package.json` و `vercel.json` باید در همان ریشه باشند.
۲. پروژه را به Vercel متصل کنید. فرمان ساخت `npm run build` و پوشهٔ خروجی `dist` در پیکربندی ثبت شده‌اند. ساخت سایت وابستگی npm بیرونی یا Python لازم ندارد.
۳. اگر دامنهٔ نهایی شما با دامنهٔ اصلی پروژهٔ Vercel متفاوت است، متغیر **SITE_URL** را با نشانی کامل HTTPS و بدون مسیر تنظیم و دوباره منتشر کنید؛ مثال: `https://your-domain.example`.

اولویت تعیین دامنه: `SITE_URL`، سپس `VERCEL_PROJECT_PRODUCTION_URL`، سپس دامنهٔ موجود در ضمیمه یعنی `https://dr17.vercel.app`. `VERCEL_URL` که نشانی یک استقرار موقت است، در canonical استفاده نمی‌شود. این دامنهٔ پیش‌فرض از فایل ضمیمه گرفته شده و تأیید مالکیت یا بررسی نسخهٔ زندهٔ آن انجام نشده است.

نسخه‌های Vercel با `VERCEL_ENV` غیر از `production` دارای `noindex, follow` هستند. در این حالت robots.txt مسیر صفحات را مسدود نمی‌کند، تا ربات بتواند دستور noindex را بخواند؛ نقشهٔ سایت نیز در robots نسخهٔ آزمایشی معرفی نمی‌شود. تنظیم صحیح محیط Production هنگام انتشار ضروری است.

## نشانی‌ها و حفظ مسیرهای قبلی

- خانهٔ فارسی روی `/` منتشر می‌شود؛ `/fa/` با انتقال دائمی به آن می‌رود.
- خانهٔ انگلیسی `/en/` و خانهٔ عربی `/ar/` است.
- صفحات داخلی فارسی همچنان زیر `/fa/` هستند.
- canonical، hreflang، x-default، داده‌های ساختاریافته، پیوندهای ناوبری و نقشهٔ سایت با همین نشانی‌ها هماهنگ‌اند.
- ۱۴۲ مسیر قدیمی یا فایل‌محور، از جمله نسخه‌های `index.html` و `index`، در `vercel.json` به نشانی اصلی متناظر انتقال دائمی دارند. این قواعد در سرور محلی آزمون شده‌اند؛ رفتار نهایی Vercel باید پس از انتشار بررسی شود.

## اتصال Search Console

در صورت انتخاب روش HTML tag، **فقط مقدار توکن** تأیید را در `GOOGLE_SITE_VERIFICATION` بگذارید؛ خود تگ HTML را وارد نکنید. سپس دوباره Build و Deploy کنید. روش DNS نیز می‌تواند در حساب مالک دامنه استفاده شود. پس از تأیید مالکیت، `https://YOUR-DOMAIN/sitemap.xml` را ثبت و صفحهٔ اصلی و چند صفحهٔ داخلی هر زبان را با URL Inspection بررسی کنید. این بسته به حساب‌های شما دسترسی ندارد و این مراحل حساب‌محور را انجام نداده است.

## فایل HTML جداگانه

`didgar-seo.html` نسخهٔ مستقل برای مشاهدهٔ آفلاین است. هر ۶۹ صفحه، تصاویر، CSS و JavaScript در همان فایل قرار دارند؛ فرم، جست‌وجو، برنامه‌ریز و تغییر زبان با فعال‌بودن JavaScript مرورگر در دسترس‌اند. فایل‌های واقعی قلم Vazirmatn برای فارسی و Cairo برای عربی در HTML جاسازی شده‌اند و برای نمایش این دو قلم به اینترنت نیاز نیست. زبان هر صفحه و عبارت‌های چندزبانه، قلم مناسب را تعیین می‌کند. ارسال واتساپ و بازکردن منابع بیرونی به اینترنت نیاز دارد.

HTML مستقل با `noindex` تهیه شده است. برای انتشار و سئوی صفحات دارای نشانی مستقل، بستهٔ چندصفحه‌ای ZIP را استفاده کنید. نشانی‌های مبتنی بر `#` در یک فایل جایگزین صفحات مستقل برای سئو نیستند. HTML مستقل عمداً وارد `dist` نمی‌شود.

## قلم‌های فارسی و عربی

در سایت منتشرشده، Vazirmatn و Cairo از فایل‌های WOFF2 محلی در `assets/fonts/` بارگذاری می‌شوند؛ `font-display: swap` و پیش‌بارگذاری قلم اصلی صفحه نیز تنظیم شده‌اند. عنوان‌ها، متن‌ها، فیلدهای فرم و گزینه‌های زبان از قلم زبان خود استفاده می‌کنند. وزن‌های متغیر، حالت بدون JavaScript و تغییر زبان در HTML مستقل پوشش داده شده‌اند. قلم انگلیسی Inter مطابق نسخهٔ قبلی از Google Fonts درخواست می‌شود. مجوزهای اصلی OFL در همان پوشه و منشأ فایل‌ها در `assets/fonts/FONT-SOURCES.md` موجود است.

## آزمون و نگهداری

```sh
npm test
npm run build
npm run test:build
npm run test:http
npm run dev
```

سرور محلی `http://127.0.0.1:3000` فایل‌های `dist` را نشان می‌دهد. اگر HTML را مستقیم ویرایش کردید، پیش از پیش‌نمایش دوباره Build کنید.

برای بازتولید همهٔ صفحات از قالب‌های اصلی، Python و بسته‌های `requirements-maintenance.txt` لازم‌اند. این نیاز فقط برای نگهداری محلی است:

```sh
python3 scripts/generate_content.py
python3 scripts/seo-check.py
npm run build
python3 scripts/seo-check.py dist
python3 scripts/standalone.py /absolute/path/didgar-seo.html
python3 scripts/standalone-check.py /absolute/path/didgar-seo.html
```

عنوان‌ها، توضیح‌ها و پیوندهای موضوعی در `scripts/seo_config.py` تعریف شده‌اند. متن‌ها و قالب‌ها در `scripts/generate_content.py` هستند. تاریخ `UPDATED` تاریخ اصلاح واقعی محتواست؛ آن را فقط با اصلاح معنادار عوض کنید. تغییر JSON به‌تنهایی صفحات HTML را تغییر نمی‌دهد. اجرای مولد، ویرایش دستی HTMLهای تولیدشده را بازنویسی می‌کند. هنگام تغییر نشانی یا افزودن صفحه، قواعد انتقال در `vercel.json` را نیز متناسب با مسیرهای جدید بررسی کنید.

## تماس و فرم

شمارهٔ اصلی و پیوندهای اجتماعی موجود در ضمیمه حفظ شده‌اند. API درخواست را اعتبارسنجی و پیوند پیام واتساپ را آماده می‌کند؛ ارسال واقعی فقط با بازکردن واتساپ و تأیید بازدیدکننده انجام می‌شود. هیچ پیام آزمایشی برای شخص دیگری ارسال نشده است. فرم پایگاه داده و صندوق ورودی داخلی ندارد.

## مدارک بررسی

- `SEO-AUDIT-FA.md`: یافته‌ها، اصلاحات، آزمون‌ها و موارد پس از انتشار.
- `SOURCES.md`: منابع رسمی بررسی حاضر، با تاریخ مراجعه.
- `AUDIT-PREVIOUS-FA.md` و `SOURCES-PREVIOUS.md`: مدارک قبلی داخل ضمیمه، برای سابقه؛ گزارش این بررسی نیستند.
- `reference/original.html`: مرجع قدیمی موجود در ضمیمه، دست‌نخورده و خارج از خروجی انتشار.

آزمون ساختاری، HTTP و ساخت دامنه انجام شده است. مرورگر Chromium در این محیط موجود نبود؛ آزمون تصویری مرورگر، Lighthouse، Rich Results Test آنلاین و اندازه‌گیری واقعی LCP/CLS/INP انجام نشده‌اند. بررسی رتبه، ترافیک، نمایه‌شدن و کارایی واقعی پس از انتشار به نسخهٔ زنده و داده‌های حساب مالک سایت نیاز دارد.

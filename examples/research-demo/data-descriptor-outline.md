# Teaching Data Descriptor outline

**Entirely synthetic demonstration; not a submitted or eligible journal paper.**

Background: the 12 invented records demonstrate dictionaries, validation,
versioning and descriptive analysis. They cannot establish student-population
findings or real measurement validity.

Methods: values were authored for teaching, not sampled from people. The dictionary
defines five columns. `research.py` checks schema, IDs, finiteness, ranges and flags
before computing outputs. No missing-data procedure is implemented.

Data records: `synthetic.csv` version 1.0.0, its dictionary and the SHA-256 in
`outputs/summary.json` identify the supplied input. A real Data Descriptor would
need an appropriate actual repository record and current outlet requirements.
No fictional DOI or accession is supplied.

Technical validation: six executable tests check known-answer calculations,
normal tails, input failures and output agreement. These validate specified
teaching behaviours, not instrument validity or external generalization.

Usage: run the commands in README. The expected mean is 808/12 and the six path
sample counts are 12/12, 10/10 and 8/8. All coefficients are descriptive. Do not
reuse the illustrative quality flags as real exclusions.

Availability: code MIT, invented records CC0, no third-party content or institute
branding included in the grants. Actual human data require consent, rights and
identification-risk assessment. Follow Scientific Data's current instructions
for a real submission rather than copying this outline as if it met them.

# مشروع تعليمي قابل للتنفيذ

السجلات الاثنا عشر اصطناعية بالكامل، وليست نتائج طلاب حقيقيين أو مراجعة أو قبولاً
من مجلة. الكود مثال صغير وليس برنامجاً مؤهلاً لـ JOSS أو بديلاً لتحليل متخصص.

من هذا المجلد وباستخدام Python 3.10 أو أحدث:

```sh
python3 research.py
python3 test_examples.py
python3 equivalence.py
```

لا تحتاج هذه الأوامر مكتبات خارجية. افتح `outputs/index.html`. تفحص العملية
المدخل وتولد الملخص وستة مسارات انحدار وصفية وSVG وبصمة الملف وأمثلة TOST منفصلة.
مجموع الدرجات الاصطناعية ٨٠٨ ومتوسطها ٦٧٫٣٣٣٣٣٣ وانحراف العينة نحو ٩٫١٢٨٧٠٩.

تتقاطع ثلاث قواعد تعليمية (الكل، استبعاد A، استبعاد A وB) مع نموذجين وتكون
الأعداد ١٢/١٢ و١٠/١٠ و٨/٨. لا تبرر الرموز استبعاد بيانات فعلية. لا يقدم المثال
فترات ثقة أو تصحيح تجميع أو اختباراً رسمياً لمنحنى المواصفات أو قوة أو سببية.

TOST مستقل عن CSV ويستخدم تقديراً ٠٫٢٠ وSE=٠٫١٥ أو١ وحدوداً تعليمية ±٠٫٥.
في الأول CI90 نحو [−٠٫٠٤٦٧٢٨،٠٫٤٤٦٧٢٨] وp نحو٠٫٠٢٢٧٥٠؛ يدعم النموذج الطبيعي
التكافؤ مع احتواء CI95 للصفر، ويكون SE=١ غير حاسم. برر الفروض فعلياً.

تربط وثيقة Quarto الرقم بالكود وتتطلب Quarto وJupyter، وPDF يحتاج XeLaTeX
وفحص الخطوط والأشكال. اختبرت حسابات Python ولم تختبر صياغة Quarto أوWord أوPDF.
يحتاج العربي والفارسي ضبط اللغة والخط والاتجاه وفحصاً منفصلاً.

وثائق البروتوكول والرد والأطروحة ووصف البيانات تمارين مستقلة. يتاح دفتر لكل دليل
بثلاث لغات. ترخيص MIT للكود وCC0 للسجلات لا يشمل المصادر الثالثة أو علامة المؤسسة.
أعلن استخدام AI والفحوص المنفذة دون ادعاء مراجعة تخصصية مستقلة.
